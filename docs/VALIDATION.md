## 과제 요구사항별 확인

| 요구사항 | 확인 내용 |
| --- | --- |
| Idle에서 A로 AutoRun 시작 | 현재 상태가 별도 `AutoRun` 클래스의 인스턴스로 전환됨 |
| 키 조작 없이 이동 | A 키를 놓은 뒤에도 자동 이동 유지 |
| 5초 후 Idle 복귀 | 4.999초에는 AutoRun, 5초에는 Idle. Idle 대기 시간도 초기화됨 |
| 속도와 크기 증가 | Run 300 px/s, 100 × 100에서 AutoRun 600 px/s, 200 × 200으로 변경 |
| 좌우 끝 자동 방향 전환 | 양쪽 반사, 초과 이동량, 한 프레임의 여러 번 반사까지 검사 |
| 방향키로 취소 | 왼쪽·오른쪽 각각 해당 방향의 일반 Run으로 전환. 크기와 속도 복구 |
| 상태 다이어그램 | `state_diagram.png`에 상태, 전환 조건, AutoRun 속도·확대·반사 표시 |
| 기존 제어 | 방향키 반복·동시 입력, 화면 경계, Sleep과 Space 복귀 검사 |

## 실제 캔버스 확인

이미지나 캔버스를 대체하지 않고 `main.main()`으로 실제 게임 창을 열어 다음 순서로 검사했다.
게임 입력 함수에 검사 이벤트를 전달했고, 첫 AutoRun은 실제 5초가 지나도록 실행했다.

```text
Idle → AutoRun → Idle
Idle → AutoRun → Run(왼쪽) → Idle
Idle → AutoRun → Run(오른쪽) → Idle
Idle → Sleep → Idle(Space)
```

AutoRun에서 양쪽 방향을 모두 관찰했으며, 관찰된 중심 x좌표는 약 101.77~699.29로
확대된 캐릭터의 허용 범위 100~700 안에 있었다. 일반 상태로 돌아오면 그리기 크기가
100 × 100이 되는지 확인했다. 종료 이벤트 후 캔버스가 정상적으로 닫혔다.

과제 폴더의 상위 폴더에서 실행하여, 실행 위치와 무관하게 포함된 이미지의 절대 경로가
올바르게 계산되는지도 확인했다.
